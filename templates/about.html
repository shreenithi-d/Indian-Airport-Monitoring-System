Indian Airport Monitoring System

Smart Airport Map, Flight Tracking and Ticket Booking

1. System Identity and Objective

The Indian Airport Monitoring System (IAMS) is an integrated aviation management platform engineered to demonstrate high-standard full-stack web architecture. It combines geographical mapping of 110+ verified Indian airports, flight scheduling, status tracking, top-down aircraft cabin visualization with gender-based seat assignments, and transactional ticket booking.

2. Architecture & Technology Stack
Backend Stack
  • • Python 3 & Flask Application Factory
  • • Flask-SQLAlchemy (Relational ORM)
  • • Flask-Login (Session User & Role Authentication)
  • • Flask-WTF & WTForms (CSRF & Form Protection)
  • • SQLite Database (Local & ACID Compliant)
Frontend Stack
  • • Bootstrap 5 (Responsive Grid & Modern Components)
  • • Leaflet.js & OpenStreetMap Tiles
  • • Chart.js (Operational Analytics Visualizations)
  • • Custom Aviation CSS & Interactive Seat Map
  • • Vanilla JavaScript (Asynchronous requests & Dom Logic)
3. Gender-Coded Seat Map Innovation

A dedicated capability of this application is the visual gender allocation on aircraft seats. Male travelers are displayed in light blue (#DCEBFF with border #4385E8), female travelers in light pink (#FFE0EC with border #E66B9A), and undisclosed passengers in neutral gray. Backend transaction safety protects against double bookings and releases seats immediately upon cancellation.
