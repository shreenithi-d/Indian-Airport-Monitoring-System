Live Aviation API Gateway Integration

To connect a third-party commercial aviation telemetry provider (e.g., AviationStack, FlightAware, OpenSky), configure the provider credentials in your .env file. In absence of external credentials, the platform utilizes its persistent database model and reference schedule timetable.

AVIATION_API_PROVIDER=NONE_FALLBACK_TO_DATABASE
AVIATION_API_KEY=<configured-in-env>
